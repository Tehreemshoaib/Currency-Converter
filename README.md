# Currency-Converter
A Java console based Currency Converter built using Object-Oriented Programming principles. It Implements abstraction, inheritance, and encapsulation to manage source and target currencies. It supports multi-currency conversion through structured switch case logic with predefined exchange rates and formatted output handling.

# Features
Convert between 15+ international currencies
User-friendly menu-driven interface
Structured source and target currency selection
Formatted output with precise decimal values
Exception handling for unsupported conversions

# Technical Implementation
The system is designed using abstraction, inheritance, and encapsulation. An abstract Currency class defines shared behaviors, while SourceCurrency and TargetCurrency extend it to manage user selections. The CurrencyConverter class handles conversion logic using predefined exchange rates and structured switch-case implementation.

# Technologies Used
Java
Object-Oriented Programming (OOP)
Console-based interface

# How to Run
Compile the program using a Java compiler.
Run the Main class.
Select source and target currencies.
Enter the amount to convert.
